# Weather Model Fight Club

A fight-night comparison of GFS, ECMWF, and ICON forecasts across three consecutive days. The Node server geocodes a location, requests all three global models from Open-Meteo, normalizes their hourly output, and passes only structured values into a deterministic comparison engine. The UI never reads raw provider responses.

## Run

```bash
npm start
# open http://localhost:3000
```

No API key or package installation is required. Node 20+ is sufficient. Live use requires internet access to Open-Meteo.

## Model Agreement formula

For a two-model comparison, compute `min(abs(GFS − ECMWF) / cap, 1)`. In tournament mode, use the range `max(model values) − min(model values)`. The caps are 20°F for temperature, 100 percentage points for precipitation probability, and 30 mph for wind. Penalties are weighted 35%, 40%, and 25% respectively.

`Model Agreement = round(100 × (1 − weighted penalty / available weight))`

At least two model values are required for a tournament round. Otherwise its weight is excluded. “Closest to consensus” is the smallest normalized distance from the per-metric median; it does not identify the most accurate model. This is forecast similarity—not confidence, accuracy, or a probability of correctness.

## Architecture

```text
Open-Meteo → src/weather.js normalization → src/agreement.js → JSON API → UI
                                                        ↘ structured fallback commentary
```

An external LLM is intentionally optional. The included grounded commentator uses only calculated comparison data, so weather retrieval and scoring continue to work if no LLM is configured.

## Local fight archive and evaluation

Every completed matchup is saved in the current browser's `localStorage` under `wmfc:fight-cards` (maximum 30 cards). Open **Fight Archive** to view three-day model trajectory graphs, forecast ranges, a fantasy-style bracket, and verified results. Nothing is uploaded by the archive feature.

**Surprise Me** randomizes the location, forecast hour, and three-model roster. The verified global draw pool currently contains GFS, ECMWF IFS, ICON, GEM, JMA, and UKMO Global. A missing model variable is displayed as unavailable and excluded according to the normal scoring rules. ACCESS-G is recognized by the provider adapter but excluded from random draws because the unified endpoint can return empty hourly series for it.

After a forecast hour has passed, **Evaluate Past Rounds** requests Open-Meteo ERA5 gridded historical weather. It is an historical estimate, not a station observation, and can be delayed by several days. Evaluation uses:

- 40% temperature absolute error, capped at 20°F
- 25% wind absolute error, capped at 30 mph
- 35% precipitation-probability Brier score against precipitation of at least 0.004 inches

The highest normalized evaluation score leads that archived round. This historical evaluation is separate from Model Agreement and is never generated by an LLM.

## Verification

Run deterministic unit and adapter tests with `npm test`. Suggested Kane flows: valid city matchup, change time and confirm values update, invalid location error, mobile viewport, and upstream/LLM-unavailable resilience.
